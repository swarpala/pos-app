# 판매 관리 POS 설치 안내

인터넷 없이 실행되고, 데이터는 아이폰(아이패드) 안에만 저장되는 홈 화면 웹앱입니다.
서명, Xcode, 맥이 필요 없고 7일 만료도 없습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 앱 본체 |
| manifest.webmanifest | 홈 화면 앱 이름과 아이콘 정보 |
| sw.js | 오프라인 실행용 캐시 |
| icon-192.png, icon-512.png, apple-touch-icon.png | 앱 아이콘 |

## 1. 무료 호스팅에 올리기 (GitHub Pages 예시)

1. github.com 에서 새 저장소를 만듭니다. 이름은 자유이고 Public 으로 둡니다.
2. 저장소 화면의 "uploading an existing file" 로 이 폴더 안의 파일 6개를 모두 올립니다. 폴더째가 아니라 파일 6개를 저장소 맨 위에 올려야 합니다.
3. Settings > Pages 에서 Branch 를 main, 폴더를 / (root) 로 두고 Save 를 누릅니다.
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 주소가 생깁니다.

Cloudflare Pages 나 Netlify 에 파일을 끌어다 놓는 방식도 같은 결과입니다.
올린 주소는 누구나 열 수 있지만, 판매 데이터는 각자 기기 안에만 있고 서버로 가지 않습니다.

## 2. 아이폰에 설치하기

1. 아이폰 Safari 로 위 주소를 엽니다. (다른 브라우저가 아니라 Safari 여야 합니다.)
2. 공유 버튼 > "홈 화면에 추가" > 추가.
3. 홈 화면의 "판매관리" 아이콘으로 한 번 실행합니다. 인터넷이 연결된 상태여야 오프라인용 캐시가 저장됩니다.
4. 비행기 모드로 바꾼 뒤 다시 실행해서 열리는지 확인합니다.

## 주의할 점

- Safari 에서 입력한 데이터와 홈 화면 앱의 데이터는 서로 따로 저장됩니다. 설치 후에는 홈 화면 아이콘으로만 사용하세요.
- 앱 아이콘을 삭제하면 데이터도 함께 사라집니다. 메뉴의 "백업 내보내기"로 가끔 파일을 저장해 두세요. 공유 시트에서 "파일에 저장"을 고르면 됩니다.
- 새 기기나 재설치 후에는 메뉴의 "백업 불러오기"로 복구합니다.
- 처음 설치하면 품목과 거래가 비어 있습니다. 메뉴의 "예시 데이터로 덮어쓰기"를 누르면 시험용 데이터가 들어갑니다.

## 앱을 수정했을 때

index.html 을 새 파일로 다시 올린 뒤, 인터넷이 연결된 상태에서 앱을 두 번 실행하면 새 버전이 적용됩니다. 첫 실행에서 새 버전을 내려받고, 두 번째 실행부터 보입니다. 아이콘 같은 파일 목록이 바뀌었을 때는 sw.js 맨 위의 `pos-v1` 을 `pos-v2` 로 올려 주세요.
